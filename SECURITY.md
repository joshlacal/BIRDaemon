# Security policy

Security fixes target the latest development revision of BIRDaemon. Older
revisions are not maintained separately.

Please report vulnerabilities privately to `joshlacal@gmail.com` with
"BIRDaemon security report" in the subject. Include the affected revision,
impact, and reproduction steps, but do not include live credentials in the
initial report. Please do not open a public issue for an unpatched
vulnerability. The maintainer will coordinate investigation, a fix, and
disclosure with you.

Reports involving the MLS protocol or a shared Catbird dependency may require
a fix in that dependency as well as BIRDaemon.
